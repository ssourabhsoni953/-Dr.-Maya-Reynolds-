# Dr. Maya Reynolds, PsyD — Practice Website

A website for Dr. Maya Reynolds, PsyD, a licensed clinical psychologist in Santa Monica, California, specializing in therapy for anxiety, panic, trauma (EMDR), and burnout.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS & Custom CSS
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

To create an optimized production build:
```bash
npm run build
```
